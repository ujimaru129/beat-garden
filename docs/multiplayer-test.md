# 2〜3人での動作確認の手順

目的：領地が人ごとに分かれるか、他の人の物が見えないか、購入・保存・ランキングが正しく動くかを確かめる。
Studio だけで確認できる部分（A）と、公開してから確認する部分（B）に分ける。結果は、チェックを付けて、気になる点をスクリーンショットで教えてもらう。

## A. Studio で確認する（公開しなくてよい）

### 準備
1. Studio でゲームを開き、Rojo の「Connect」を押す
2. 上のリボンの **「Test」タブ**を開く。見つからないときは、リボンの右端の「…」か、メニューの「View」から探す（以前、リボンに見当たらなかった）
3. **「Clients and Servers」**（クライアントとサーバー）の項目で、**Players を 2 または 3**にして、**Start** を押す
   - ウィンドウが、サーバー1つと、プレイヤー2〜3つで開く。タイトルに「Client 1」「Client 2」などと出る

### 確認する項目
| 確認すること | 期待する結果 | 結果 |
| --- | --- | --- |
| 領地の場所 | プレイヤーごとに、別の領地（植え場のまとまり）の入口に出る。重ならない | ☐ |
| 光の柱と光る道 | 自分の領地にだけ見える。他の人の画面には、他の人の分が出ない（自分の画面で、他の人の領地の柱が見えない） | ☐ |
| 植物 | 自分の画面で、他の人の植物は見えるが、触って世話・収穫はできない（「This is not your plant」と出る） | ☐ |
| スピリット | 装備したスピリットが、自分の画面にだけ出る（他の人の画面には出ない） | ☐ |
| 昼夜・BPM Rush | 全員の画面で、同じ時刻に切り替わる。バナーの残り時間が、ほぼ同じ | ☐ |
| ショップの在庫 | 全員で、同じ在庫が出る（5分ごとに入れ替わるタイミングも同じ）。レベルが違えば、並ぶ種が違う | ☐ |
| リズム中 | 自分がリズムをしている間、他の人の動きが、邪魔にならない（レーンの前に、他の人が立っていても、隠れる） | ☐ |
| 退出 | 1人が退出して、また入ると、同じ領地に戻る、または別の空いた領地になる。そのとき、前の植物が、消えずに残っている（Studio では保存されないので、残らないのは正常） | ☐ |
| 領地の数 | 8人を超えると、案内が出る、または参加できない（ここは、8人で試すのは大変なので、後回しでよい） | ☐ |

### 気をつけること
- Studio のテストでは、データの保存が動かない（未公開のため）。保存の確認は、B で行う
- テスト用のキー（L、G、C、P）は、Studio だけで使える。各ウィンドウの、一番手前（選択中）のウィンドウで動く
- 重いときは、Players を 2 にする

## B. 公開してから確認する

### 準備
1. Studio で **File → Publish to Roblox** でゲームを公開する（まずは「非公開（自分だけ）」のままでよい。グループやフレンドに限定する設定もある）
2. Creator Hub の「課金」と「ランキング」の設定が済んでいることを確認する（課金の ID が入っていること）
3. 別のアカウント（パスを持っていない、友だちか、テスト用のアカウント）を用意する

### 確認する項目
| 確認すること | やり方 | 期待する結果 | 結果 |
| --- | --- | --- | --- |
| 保存 | 植物を植えて、コインを貯める。ゲームを終了して、入り直す | 植物、コイン、レベル、星、スピリットが残っている | ☐ |
| 領地（別アカウント） | 2つのアカウントで、同じサーバーに入る | 領地が別々。互いの植物が見えるが、触れない | ☐ |
| パスの購入 | パスを持っていないアカウントで、ショップの下の「Double Growth」（または Plot Pass の金の区画）を押す | Roblox の購入画面が出る。購入後、すぐ効果が出る（成長が2倍になる／金の区画が開く） | ☐ |
| 開発者商品 | 同じアカウントで、Instant Grow、Restock、Look Sprinkler を買う（少額） | 購入後、効果が出る。ゲームを入り直しても、二重に付与されない | ☐ |
| ランキング | 2つのアカウントで、レベルを上げる。5分ほど待って、Ranking ボタンを開く | 両方の名前と値が、順位つきで出る。自分の行が黄色 | ☐ |
| 音と譜面 | 新曲を、数曲遊ぶ（特に Naniwa March、Fly Me to the Saitama、Gorilla Glue） | 音が鳴る。ノーツが拍に合っている | ☐ |
| ジャケット | 曲選択を開く | 10曲分の絵が出る。最初のうちに遅くない | ☐ |
| 夜の見た目 | 毎時の55〜60分に、ゲームの中にいる | ネオンの景色。重くない | ☐ |
| 低めのスマホ | 古い、または低価格のスマホで、Hard のリズムを遊ぶ | 動作がカクつかない（Metropolitan Expressway の Hard は、特に重い曲） | ☐ |
| 課金なしで遊べるか | 課金せずに、レベル10くらいまで遊ぶ | 全部の種と曲を、課金なしで遊べる。課金の案内が、しつこくない | ☐ |

## 結果の伝え方
- **うまくいった項目:** 「A 領地 OK」のように、一言でよい
- **うまくいかなかった項目:** その画面のスクリーンショットと、「何をしたら、どうなったか」を教えてもらう。Studio の「出力（Output）」に赤い文字が出ていたら、その文章も
- 後で直す項目と、すぐ直す項目を、一緒に決める
