# 公開の手順と年齢の質問票（Beat Garden）

画面の名前は、Roblox の更新で変わることがある。見つからないときは、近い名前の項目を探す。

## 1. 年齢の質問票（コンテンツのレーティング）

場所：Creator Hub → 作品 → Beat Garden → 左のメニュー **「公開設定」→「コンテンツのレーティング」**（質問票、Maturity）

答えは、**このゲームの実際の中身**で、正直に答える。公開前に決めておく答えの目安：

| 質問の種類 | このゲームの答え | 理由 |
| --- | --- | --- |
| 暴力、血、恐怖、ホラー | **なし** | 植物を育てるだけ。戦いや怖い表現はない（夜は、ネオンの景色だけ） |
| 下品な表現、ののしり言葉 | **なし** | ゲームが出す文章に、ない。プレイヤーの自由な文章も、表示しない |
| 恋愛、性的な内容 | **なし** | ジャケットの絵は、手をつなぐ程度（Shinjuku Deep Romance の絵が、問われたら、「寄り添う様子」と答える） |
| アルコール、タバコ、薬物 | **なし** | |
| ギャンブル、くじ | **なし**（ただし、下の「ランダム」を確認） | 現金や Robux を賭ける要素はない |
| **有料ランダムアイテム（Robux で買う、直接または間接）** | **なし** | 卵は、**コインで買い、コインは Robux で買えない**。Robux の商品は、どれも確定の効果で、確率を変えない（Growth Sprinkler は、確率ではなく、成長の速さ） |
| 課金 | **あり** | パス（2つ）と開発者製品（3つ）がある。種類は、時間短縮と、少しの運の足し |
| ユーザー同士の交流 | **あり** | 交換（実、種、スピリット）。Roblox 標準のチャットが、使える設定のままなら、「チャットあり」 |
| ユーザーが作る内容（UGC） | **なし** | プレイヤーが、絵や文章を、ゲームに入れることはない |
| ランキング | **あり** | ユーザー名のみ表示（Roblox のユーザー名） |
| 外部サイトへのリンク | **なし** | |
| 音楽 | **あり** | 自作の楽曲（権利は確認済み） |

迷う質問は、「より厳しい方」に倒して、答える。分からない用語は、その画面のスクリーンショットを見せてもらえば、一緒に決める。

## 2. 公開前に、Studio で確認すること

1. **Rojo の「Connect」を押して、最新のコードが、Studio に入っている**ことを確認する（Studio の「Explorer」で、ServerScriptService / ReplicatedStorage に、最新のスクリプトがあるか）
2. Studio の **File → Game Settings（ゲーム設定）→ Security（セキュリティ）** で、**「Enable Studio Access to API Services」**がオンであること（オンになっている）
3. 同じ画面の **Basic Info** で、名前（Beat Garden）、ジャンル（シミュレーション）、対応デバイス（スマホ、タブレット、PC）を確認する
4. 同じ画面の **Permissions** で、**「Private（非公開）」のまま**にしておく。最初は、自分だけ、または、招待した人だけで、確認する

## 3. 公開（Publish）

1. Studio で、**File → Publish to Roblox**（または、「Publish As」）を押す
2. すでに作ってある「Beat Garden」のゲームを、選ぶ（新しく作らないこと。新しく作ると、別のゲーム ID になり、課金の ID も、ランキングも、別になってしまう）
3. 公開が終わったら、Creator Hub の「作品 → Beat Garden → プレース」で、**更新日時が、今になっている**ことを確認する

## 4. 公開範囲（誰が遊べるか）

場所：Creator Hub → Beat Garden → 左のメニュー **「公開設定」→「オーディエンスを管理」**

- **非公開（Private）:** 自分だけ。最初は、これで確認する
- **友だち、グループ、特定のユーザーだけ:** テスト用のアカウントや、友だちを入れる。2人以上の確認に使う
- **公開（Public）:** 誰でも遊べる。ローンチ（12月24日）のときに、切り替える

## 5. 公開後の確認（最初の10分）

1. Roblox のアプリ、または、サイトで、ゲームのページを開く（自分のアカウント）
2. 入って、植物を植えて、少し遊ぶ。コインを貯める
3. ゲームを終了して、入り直す。**植物、コイン、レベルが、残っている**か（保存の確認）
4. ショップの下の、Robux の項目を押して、購入画面が出るか（開発者製品は、実際に Robux を使うので、25 R$ の Instant Grow など、少額で）
5. Ranking ボタンを開く（数分後に、順位が出る）

詳しい確認の表は、[multiplayer-test.md](multiplayer-test.md) の B を見る。

## 6. 困ったとき

- **戻したい:** Creator Hub の「バージョン履歴」（Place の履歴）から、前のバージョンに戻せる
- **保存されない:** Studio の「API サービス」の設定と、公開済みかを確認する。出力（Output）の赤い文章を見せてもらう
- **購入画面が出ない:** 製品の ID と「販売中（有効）」の設定を確認する
- **ローンチ前に、人に見られたくない:** 公開範囲は、必ず、非公開、または、限定のままにする
