# 庭の進化「Beat Park」とペット化（設計メモ・下書き）

目的：植えて収穫したあとも「自分の世界が変わっていく」楽しみを作る。人によって違うデザインになり、見せ合える。
コードは未着手。ここは、決めたことと、作る順番。

## 1. 世界が育つ：パーク（遊園地）

- 各自の領地の**うしろ（地上）と上（空中）**に、アトラクションを置く「区画（ロット）」がある。
  - 地上 3、空中 3。レベルで開く（地上: Lv3 / 8 / 14、空中: Lv6 / 11 / 17）。
  - 広さが足りないところは、空中ブランコ、空中のジェットコースターなど**空に作る**。
- アトラクションは**ギフトボックス**から出る。中身は開けるまで「???」。
  - 例（地上）：噴水、メリーゴーラウンド、コーヒーカップ、観覧車、ステージ（夜はレーザー）、花火台
  - 例（空中）：空中ブランコ、空中ジェットコースター、風船の束、提灯のつなぎ、雲のすべり台
  - 同じアトラクションにも**色違い**がある（Sakura / Sora / Yuzu / Matcha、まれに Rainbow）。持つのは「種類×色」。
- ギフトボックスは**目標のクリア**でもらう（Robux では買えない。有料ランダムにしない）。
  - 例：収穫 5 / 20 / 50 / 100 回、リズムを 5 / 20 / 50 回プレイ、100 コンボ、図鑑 5 / 15 / 30 個、スピリット 1 / 3 / 5 匹、レベル到達
  - 目標の進み具合は、画面に出す。
- どの区画に何を置くかは、**自分で選ぶ**。ほかの人の領地からも見える（見せ合い）。
- 動き（回る、揺れる）は、既存の `WorldFx` のタグ（Spin / Bob / Orbit / Pulse）で、クライアント側で動かす。

## 2. スピリットのペット化

- 持っている**全員**が、パークや庭を歩き回る（今は装備した 1 匹だけ）。
- 連れて歩く（ついてくる）のは、装備した 1 匹（効果もこれまでどおり）。
- なでる（タップ）とハートが出て、**なかよし度**が上がる。
- 名前を付けられる（候補：決まった名前の一覧から選ぶ。自由入力は使わない）。
- ほかの人の領地のスピリットも見える。

## 3. 見せ合い（あとで）

- 領地に、ハートの看板。訪れた人が「いいね」を押せる（1 人 1 回）。
- ランキングに「パークのいいね」の欄を足す。

## 4. 保存するデータ（案）

- `park.items`（持っているアトラクション）、`park.boxes`（未開封の箱の数）、`park.claimed`（受け取った目標）、`park.placed`（区画 → アトラクション）
- ペット：`spirits[].bond`（なかよし度）、`spirits[].nick`（名前の選択肢）
- 形が変わるので、`PlayerData.Version` を上げて、`sanitize` に移行を足す。

## 6. 注意

- 見た目の部品は、パーツの組み合わせで作る（重くしない）。8 人分で数千パーツまで。
