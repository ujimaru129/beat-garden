# 公開前チェックリスト（ローンチ 2026/12/24）

コードで確認できたこと、あなたの作業、公開してから確認することに分ける。更新日：11/10。

## コードで確認・対応済み

- 数値の判定、報酬、価格は、すべてサーバーが決める（画面側は表示だけ）
- Robux の購入：購入 ID を保存データに覚えて二重に付与しない。付与のあと保存してから確定する（`Garden.processReceipt`）
- サーバーの呼び出し（Remote）に、1人あたり毎秒10回・最大30回の制限を付けた。超えたら「too fast」と返す
- 保存：セッションロック付きの DataStore。保存できない環境（未公開・Studio）では、その旨をログに出し、遊べるが保存はされない
- ランキング：書き込みは1分に1回まで、読み込みはサーバーのキャッシュ（2分ごと）。失敗しても `pcall` でゲームは止まらない
- Studio 限定のテスト用キー（P、L、G、C）は、サーバー側で `RunService:IsStudio()` を確認して、製品版では動かない
- プレイヤーが自由に入力する文字は、どこにも無い（チャット、名前の入力など）。表示に出るのはユーザー名だけ
- 有料のランダム要素（スピリットの卵）は、ショップの説明に確率を表示している
- 課金の導線は、ショップの一番下に控えめに置いた。課金しなくても、全部の種と曲を遊べる
- 交換は、双方の確認が要る2段階で、ログを残している
- 低画質向けの軽量モード（ブルームとパーティクルを減らす）がある

## 気をつけること

- 保存の形を変えるときは、`PlayerData.Version` を上げて、`sanitize` に移行の処理を足す
- 数値（レベルの必要量、価格、確率）は、`docs/progression.md` に書いてある。変えたら、そこも直す
- ランキングの名前は、Roblox のユーザー名をそのまま出している。表示名（Display Name）は使っていない
